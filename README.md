# coldfiregames.app

The ColdFire Games website: home (Pyrograph), support, privacy policy, and `app-ads.txt`. Plain HTML and CSS, no build step, no web fonts or trackers. Published with GitHub Pages; `CNAME` sets the custom domain.

- Edit pages directly; `style.css` holds the shared look.
- Add each ad network's line to `app-ads.txt` as accounts are created.
- Update the date at the top of `privacy.html` whenever the policy changes.
